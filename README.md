# Customer Churn Insights Dashboard

## Project Overview
The Customer Churn Insights Dashboard is a data analytics project built using Microsoft Power BI and Excel. It focuses on exploring customer churn patterns and understanding customer retention through data visualization.

## Project Objectives
- Analyze customer churn patterns.
- Explore customer retention trends.
- Understand customer-related data through visual analysis.
- Present insights in an interactive Power BI dashboard.

## Tools & Technologies
- **Microsoft Power BI** — Dashboard creation and data visualization
- **Microsoft Excel** — Dataset and data source
